# 3D, свет и отладка

## Камера и окружение

- В first-person вертикальный pitch хранится в диапазоне `-1.0..1.0`,
  изменяется вертикальным движением мыши и сохраняется в `settings.json`.
  `Home` возвращает pitch к `0.0`.
- 3D-доска показывает пол и вертикальные стены; наклон `PageUp/PageDown`
  позволяет смотреть сверху/снизу.
- В first-person пол и потолок проецируются как поверхности комнаты: их границы
  вычисляются из тех же DDA-лучей и высот стен, поэтому при pitch они сходятся
  и расходятся перспективно вместе со стенами. `Graphics → Ceiling` отключает
  потолочную поверхность и показывает skybox.
- Skybox предназначен для помещений без открытого неба и не имитирует
  внешний дневной пейзаж.
- Средняя кнопка мыши продолжает вращать камеру. В 3D и first-person это
  действие также дублируется удержанием `Alt` и движением мыши.
- `Graphics → Draw distance` по умолчанию равен 52 клеткам — примерно в четыре
  раза дальше прежнего радиуса лучей. Переключатель меняет стандартное и
  увеличенное значение.

## Источники света

Источником света игрока считается **надетый фонарь**. Фонари могут появляться
в наборах припасов новых чанков. Один фонарь в инвентаре без надевания не
освещает уровень.

`Shift+L` теперь требует надетый источник света. Без него действие сообщает
о необходимости источника и не тратит ход. При наличии фонаря оно включает
или выключает освещение комнат, обновляет световую сетку и тратит ход.
Внутренние источники комнат создаются генератором по центрам комнат и работают
только для комнат с флагом `lit`; стартовая комната игрока включается отдельно.
В генератор также добавлены потолочные лампы: часть центров комнат помечается
как `ceiling_lamps` и добавляется в список источников света. Состояние ламп
сохраняется вместе с уровнем.

## Debug tools

В `Settings → Debug tools` (доступно только во время игры) находятся:

- **Reveal full terrain** — открывает весь рельеф текущего уровня;
- **Immortality** — переключатель бессмертия игрока;
- **Add any item to inventory** — список всех объектов из реестра;
- **Spawn any item on floor** — список объектов и создание на свободной клетке;
- **Toggle lighting override** — переключение шейдерного освещения для тестов;
- **Change skybox color** — смена цвета skybox;
- **Fly mode** — разрешает `PageUp/PageDown` для перехода по Z;
- **No clip** — разрешает проход через стены;
- **Move one floor up/down** — переход между доступными Z-уровнями.

Debug-инструменты не добавляются в обычное радиальное меню и не требуют
специальных постоянных клавиш. Состояние бессмертия относится к текущей
игровой сессии и не сохраняется как часть обычного прогресса.
Полет и noclip также являются сессионными флагами.

## Исправление ошибки

Поле `Game.alt_camera` теперь создаётся в конструкторе каждого экземпляра
игры, поэтому обработка движения мыши не падает в тестах и при создании
игры через нестандартные вспомогательные пути. Отпускание Alt также явно
сбрасывает состояние камеры.
