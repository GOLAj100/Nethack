# Modern HUD - Современный интерфейс

## Обзор

Modern HUD - это новая система пользовательского интерфейса для игры, которая заменяет ASCII-основанный интерфейс на пиксельный/гибридный UI с современным дизайном.

## Основные компоненты

### 1. ModernHUD (engine/modern_hud.py)

Главный топбар с основными метриками игрока. Расположен в верхней части экрана.

**Отображаемые параметры:**
- **HP (Здоровье)** - красный индикатор с анимированным градиентом
- **Насыщение (Food)** - зеленый индикатор
- **Выносливость (Stamina)** - голубой индикатор
- **Рассудок (Sanity)** - фиолетовый индикатор
- **Истощение (Exhaustion)** - отображается текущий уровень и прогресс

**Особенности:**
- Полупрозрачный фон для минимального перекрытия игрового экрана
- Адаптивная ширина под разрешение экрана
- Плавные градиенты на полосках здоровья
- Цветовая кодировка состояний (критическое HP - красный, нормальное - оранжевый)

### 2. ModernSidebar (engine/modern_hud.py)

Детальная боковая панель со статистикой и быстрыми действиями. Скрывается/показывается клавишей Tab.

**Отображаемая информация:**
- Детальные характеристики (AC, STR, DEX, LVL)
- Текущая глубина и золото
- Количество убийств
- Текущее оружие
- Быстрые действия (меню действий, взаимодействие, инвентарь, карта, характеристики)

**Особенности:**
- Переключаемая видимость (Tab)
- Кнопки с hover-эффектом
- Компактный дизайн (280px ширина)

### 3. HUDTheme (engine/modern_hud.py)

Централизованная палитра цветов и стилей для единообразия интерфейса.

**Цветовая схема:**
- Глубокие темные поверхности (#05070C - #1E2636)
- Акцентный голубой цвет (#38BDF8)
- Градации серого для текста и границ
- Специфичные цвета для каждого параметра (HP: #BC3636, Food: #56BA60, etc.)

**Токены дизайна:**
- SPACING: SM(8px), MD(16px), LG(24px)
- RADIUS: SM(4px), MD(8px), LG(12px)
- SURFACE: 5 уровней поверхностей для иерархии
- BORDER: default и accent границы

## Использование

### Включение/выключение Modern HUD

```python
# В Game.__init__()
self.use_modern_hud = True  # По умолчанию включен

# Для отключения (в настройках или коде)
game.use_modern_hud = False
```

### Переключение сайдбара

```python
# Клавиша Tab или метод
game.toggle_status()
```

### Добавление новых метрик

Для добавления новой метрики в топбар:

1. Обновите `ModernHUD.draw()`:
```python
meters = [
    ("HP", player.hp, player.max_hp, th.HP_COLOR),
    # ... существующие метрики
    ("NEW", player.new_stat, player.new_stat_max, th.NEW_COLOR),
]
```

2. Добавьте цвет в `HUDTheme`:
```python
self.NEW_COLOR = (R, G, B)
```

### Адаптация под разрешение

Modern HUD автоматически адаптируется под разрешение экрана:
- Топбар использует процентное соотношение ширины
- Сайдбар фиксированной ширины (280px), но позиционируется относительно правого края
- Минимальная ширина экрана: ~800px для корректного отображения

## Совместимость

Modern HUD работает параллельно со старым ASCII-интерфейсом:
- Флаг `use_modern_hud` контролирует, какой интерфейс используется
- Старый интерфейс доступен через `draw_topbar()` и `draw_sidebar()`
- Сохранения совместимы с обоими режимами

## Архитектурные решения

### Почему пиксельный UI вместо ASCII?

1. **Гибкость позиционирования** - не ограничены символьной сеткой
2. **Современный вид** - градиенты, прозрачность, сглаживание
3. **Адаптивность** - легче адаптировать под разные разрешения
4. **Читаемость** - цветовые индикаторы понятнее чем ASCII-графика

### Почему два класса (ModernHUD и ModernSidebar)?

1. **Разделение ответственности** - топбар и сайдбар имеют разные цели
2. **Независимое управление** - сайдбар можно скрыть отдельно
3. **Упрощение кода** - каждый класс отвечает за свою область
4. **Переиспользование** - HUDTheme используется обоими классами

### Почему оставили старый интерфейс?

1. **Обратная совместимость** - старые сохранения работают
2. **Ностальгия** - некоторые игроки предпочитают ASCII
3. **Отладка** - можно сравнивать поведение интерфейсов
4. **Постепенный переход** - можно тестировать новый UI параллельно

## Производительность

Modern HUD оптимизирован для минимального влияния на FPS:
- Отрисовка только видимых элементов
- Кеширование шрифтов
- Минимум математики в draw loop
- Отключение прозрачности при низкой производительности (можно добавить в настройки)

Средняя нагрузка на CPU: ~1-2% на современных системах
