# Backrooms lore gaps: Levels 7–20

Рабочий чек-лист для следующего этапа разработки. Профили и базовая
процедурная геометрия уже существуют, но ниже перечислены элементы лора,
которых пока нет или которые представлены только упрощённой заменой.

## Общие пробелы

- [ ] Уникальные сущности уровней 7–20: отдельные записи в `game/monsters.py`,
  поведение, ограничения по B-Level и сериализация.
- [ ] Уникальные предметы лора: уровеньные ключи, документы, лекарства,
  оборудование, кристаллы, плоты, маски и специальные инструменты.
- [ ] Полноценные level-specific переходы. Сейчас большинство переходов —
  один гарантированный процедурный `Level.exits` на следующий игровой номер.
- [ ] Редкие альтернативные входы и выходы из описаний уровней.
- [ ] Отдельные правила опасностей и событий по профилям вместо общих
  `stress_interval`, `heat_interval` и простых hazards.
- [ ] Нейтральные/дружелюбные колонии, торговцы, outpost-сценарии и NPC.
- [ ] Уникальные звуковые темы и музыкальные треки по уровням.
- [ ] Уникальные atlas/PNG для больницы, авианосца, воспоминаний, отеля,
  живой архитектуры и инопланетного ландшафта.

## Levels 0–6: первый игровой кластер

Для уровней 0–6 уже есть самый полный игровой проход: базовая геометрия,
переходы, опасности света/жары, Level 6 с Z=-1 и ноуклип-маршруты. Однако
это всё ещё упрощённая адаптация, а не полная реализация статей.

### Level 0 — The Lobby

- [ ] Полная лорная бесконечность жёлтого лабиринта с большими однообразными
  комнатами, техническими коридорами и меняющейся архитектурой.
- [ ] Нестабильное освещение, гул ламп и отдельные типы неисправных ламп.
- [ ] Подробная система влажного ковролина, пятен и затопленных участков.
- [ ] Уникальные редкие сущности Level 0 и их поведение.
- [ ] Лорные входы/выходы и редкие двери вместо преимущественно гарантированного
  процедурного перехода на Level 1.
- [ ] Окончательная замена текущих вертикальных тестовых структур на реальные
  игровые вертикальные зоны, если они больше не нужны для regression-тестов.
