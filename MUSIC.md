# Музыка и звуковые эффекты

## Ползунки в игровом меню

Откройте **F2 → Звук: ползунки громкости** (рядом с размером окна,
полноэкранным режимом и графикой). Здесь шесть графических ползунков 0–100%:
общий, музыка, эффекты, окружение, тревоги, интерфейс. Перетаскивайте мышью;
стрелки влево/вправо меняют выбранное значение на 5%, вверх/вниз выбирают
строку. Home/End — 0/100%. Esc возвращает в настройки.

Окружение сейчас включает шаги, двери и лестницы; непрерывный фоновый шум
ещё не добавлен. Тревоги включают сигнал сна, низкого HP, голода и ловушки.
Музыка регулируется отдельно от всех этих эффектов. Значения применяются
сразу и сохраняются автоматически. Общая громкость умножается на выбранную
категорию, поэтому общий 0% отключает всё. F4 остаётся общим выключателем.

Музыка сканируется из `Sound trak` при запуске. MP3/OGG/WAV/FLAC проигрываются
потоком через pygame.mixer.music. Порядок внутри папки — последовательный,
после последнего трека начинается первый. Одинаковые файлы в разных папках
не удаляются: категория определяется папкой.

| Ситуация | Папка |
|---|---|
| Главное меню | Menu sound |
| Обычное исследование, Level 0 | Stranger |
| Рассудок ≤10 или видимый враг при HP ≤25% | Madness |
| Видимая враждебная сущность tier≥3 или music_mood=danger | Danger |
| Атака/промах/ранение — ещё 8 секунд после события | Attack |
| Смерть | Memory |
| Профиль снежного уровня | Snow |
| Профиль океанического уровня | Ocean |
| Безопасный/странный уровень | Happy stranger |
| Другие профили | Hotel, Hell, Heaven, Memory |

В `levels/<id>.json` укажите `"music_mood": "snow"` (или `ocean`,
`happy stranger`, `memory`, `hotel`, `hell`, `heaven`, `madness`). Для B-Level 6
по умолчанию выбирается Madness. Эти настройки не создают новые уровни.
Тревожные состояния имеют приоритет над обычной музыкой; возврат к спокойной
теме задержан, чтобы не дёргать музыку при каждом шаге у границы видимости.
Новый трек плавно нарастает за 0.8 секунды; перекрёстного смешивания двух
треков сейчас нет. Без доступного плейлиста используется Stranger.

MP4 не воспроизводится непосредственно: запустите
`python -m pip install -r requirements-audio.txt`, затем
`python tools/prepare_music.py`. Аудио извлекается в OGG в `sound_cache`.
Исходные видео не изменяются. В этой копии проекта кэш уже подготовлен.

Эффекты заменены короткими нейтральными синтезированными сигналами/шорохами;
это временные звуки, не реалистичная запись шагов или дверей. Для замены
добавьте именованные файлы в `sound/events` (см. README там).
Музыка использует 55% общей громкости, эффекты — общую громкость с учётом
громкости конкретного события. Отключение звука приостанавливает музыку и
останавливает текущие эффекты.

Проверка загрузки всех треков и переключений: `python tests/audio_music_test.py`.
