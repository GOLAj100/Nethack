# NET HACK

## Текущий этап Backrooms

**Этап 2: первый игровой проход по основным уровням 0–6.** Добавлены
разные генераторы, последовательные переходы, базовые опасности среды,
изучаемый ноуклип и сохранение посещённых B-уровней.
Управление переходами, особенности и оставшаяся работа:
[`docs/MAIN_NINE.md`](docs/MAIN_NINE.md).

Проект в сеттинг Backrooms. Предметы имеют EN/RU-названия:
жидкости в бутылках, документы, артефакты, инструменты и защитное снаряжение.
Основной каркас под ИИ есть для новых сущностей Backrooms. На уровнях 7–10 уже появляются первые
тематические сущности: The Thing, рой Mortisdoptera, The Observer и
подземный червь.

Подробное состояние, карта кода и правила следующего этапа:
[`docs/BACKROOMS_STAGE.md`](docs/BACKROOMS_STAGE.md).
Правила насыщения, пищевых сочетаний, запасов/истощения, сна и бега:
[`docs/SURVIVAL.md`](docs/SURVIVAL.md). Бег — Shift + движение,
сон на 10 ходов — Shift+B.
Описание 3D-камеры, освещения, потолка/skybox и Debug tools:
[`docs/GRAPHICS_DEBUG.md`](docs/GRAPHICS_DEBUG.md).
Описание старого NetHack-прототипа ниже содержит исторические сведения.

Рогалик в духе NetHack: процедурное подземелье, пошаговое время, ASCII-графика
с примитивной линейной оформкой (блоки `█ ▓ ▒ ░`, рамки `┌─┐│└┘`) и звук
из папки `sound/`. Интерфейс на двух языках: **English** и **Русский**.

## Настройки

В главном меню есть пункт **Settings** (`Настройки`) — туда перенесены
и язык, и звук:

- **Language / Язык** — переключение English ⇄ Русский
- **Sound / Звук** — вкл/выкл
- **Controls / Управление** — переназначение любой клавиши
- **Back / Назад** — выход

Меню остаётся открытым после переключения, чтобы сразу видеть новое
значение. Выбор сохраняется в `save/settings.json`.

Горячие клавиши прямо в игре:

| Клавиша | Действие |
|---|---|
| `F2` | настройки |
| `F3` | сменить язык на лету |
| `F4` | включить/выключить звук |

В меню инвентаря и предметов на полу есть **быстрые клавиши** — без
второго меню:

| Клавиша | Действие |
|---|---|
| `q` | выпить первое зелье |
| `e` | съесть первую еду |
| `r` | прочитать первый свиток |
| `z` | колдовать первой палочкой |
| `x` | взять в руки первое оружие |
| `Shift+W` | надеть первую броню |
| `Shift+T` | снять первое надетое |
| `Shift+D` | выбросить первый предмет |
| `i` | свойства первого предмета |
| `1`-`9`, `0` | сразу выбрать пункт меню |

Цифры `1`-`9`,`0` работают в любом меню.

### Мышь

| Действие | Результат |
|---|---|
| наведение на карту | рамка вокруг клетки |
| левый клик по клетке | пройти туда (или ударить соседа) |
| левый клик по себе | ждать ход |
| правый клик по клетке | всплывающая карточка: монстр, предмет, описание клетки |
| клик по пункту меню | выбор, повторный клик — подтверждение |
| колесо мыши | прокрутка списка |

### Переназначение управления

`Settings → Controls` показывает все 39 действий с их клавишами.
Выбери действие и нажми новую клавишу — она сразу вступит в силу и
сохранится на диск. Старые клавиши этого действия освобождаются
автоматически. Кнопка **Reset to defaults** возвращает заводские раскладки.

Заводские раскладки: WASD + vi-клавиши (`y k u / h j l / b n`) + стрелки +
numpad для движения, `>`/`<` — лестницы, `g` — взять, `,` — взять всё,
`p` — предметы на полу, `i` — инвентарь, `Shift+D` — выбросить,
`Shift+W` — надеть, `Shift+T` — снять, `Shift+F` — ударить соседа,
`f` — выстрелить, `t` — бросить, `z` — палочка, `Shift+P` — замок,
`m` — карта, `Shift+L` — свет, `c` — лист персонажа, `?` — справка,
`Shift+S` — сохранить, `Shift+Q` — сохранить и выйти.

### Справка

Экран `?` не хранит текст статично: он **строится из текущих раскладок** —
то есть всегда показывает реальные нажатия, включая переназначенные.

Если игра вдруг упадёт с ошибкой, окно больше не исчезает: показывается
экран **GAME ERROR** с текстом ошибки, а сам лог пишется в файл
`crash.log` рядом с `main.py`.

## Что внутри

- **101 B-Level (0–100)** в каталоге маршрутов: для уровней 0–20 используются
  тематические профили, а для 21–100 — утверждённая последовательность
  `docs/LEVELS_21_100_PLAN.md` с процедурным fallback-генератором. Отдельные
  лорные геометрии подключаются поверх каталога без изменения переходов.
  Основные генераторы включают комнатно-коридорные зоны и каменоломни
  (клеточный автомат)
  Диапазон 21–100 зарегистрирован в `levels/catalog.json`, а его
  процедурные профили собираются из `game/level_catalog.py`.
  и орочьи уровни с бо́льшим числом монстров.
- **Гарантии генерации**: все комнаты достижимы (флуд-заливка + добор
  коридоров), у каждой комнаты есть дверь, лестница всегда на месте.
- **Особые залы**: хранилище с запертой дверью и ценным лутом, тронный
  зал, храм с алтарём, сокровищница, казармы и фонтанный зал. Чем дальше
  от входа — тем ценнее.
- **Частично из Nethack**
  Всё что внизу остатки из первого прототипа
- **Поле зрения** — рекурсивный shadowcasting с симметризацией (свет не
  проходит сквозь стены и закрытые двери, тьма за спиной сохраняется).
- **Пошаговое время**: игрок ходит — мир отвечает. Быстрые монстры иногда делают два хода, но пока в разработке.
- **Бой**: точность попадания зависит от ловкости, урон от силы и оружия,
  броня частично гасит урон.
- **Предметы**: зелья, свитки, палочки, кольца, оружие, броня, еда, золото,
  снаряды. Зелья и свитки нужно опознавать (`scroll of identify`).
- **Голод**, статусные эффекты (опьянение, путаница, галлюцинации, сон).
- **Сохранение** в `save/slot1.json`.

## Звук

Файлы берутся из `sound/`. Раскладка событий — в `game/audio.py`
(`SOUND_MAP`, `MUSIC_MAP`). Формат: `sound/<ПАПКА>/<ПАПКА> (N).wav`.
Можно свободно заменять файлы и добавлять свои — игра подхватит их при
следующем запуске. Если каталога `sound/` нет или звуковая карта недоступна,
игра запустится без звука.

# Новые режимы графики

### Психика и уступы

После 600 ходов без сна рассудок теряет 1 единицу каждые 100 ходов.
Сон восстанавливает 1 единицу каждые 5 ходов и сокращает накопленный недосып
на 10 за ход. Видимый/близкий враждебный NPC даёт стресс (−1 каждые 20
ходов); повреждение во время хода сущностей — ещё −1. Диапазон −50..50.
Счётчики сохраняются. Отдых не заменяет сон для восстановления психики.

Действие «Подняться» (`<` в классическом наборе или через меню действий)
вне лестницы пробует карабканье. Нужен открытый объём прямо над головой и
соседний по стороне свободный уступ с полом на Z+1. Закрытый потолок,
стены и занятые клетки блокируют подъём. Требуется 5 выносливости;
попытка тратит ход. Шанс успеха 50%; при неудаче игрок остаётся внизу
и получает 1d6 урона. Лестницы работают как раньше, без броска.

## Наборы управления

### Удержание движения и сон

Удерживайте клавишу движения для повторных шагов (примерно один каждые
7 секунд); первый шаг немедленный. Shift сохраняет бег. Отпускание клавиши, потеря фокуса окна и
открытие меню останавливают повтор. В режиме осмотра 3D-карты автохода нет.

**Shift+R** или действие «Спать» открывает горизонтальный ползунок 10–360 ходов
с кнопкой «Начать сон». Он также доступен в **F2 → Длительность сна**:
перетаскивайте мышью или используйте стрелки, Enter/Esc сохраняет значение.
Сон исполняется по одному ходу с паузой 150 мс, полностью чёрным экраном
и анимацией Zzz/ZZZ. Наклон убран. Обычный отдых R/Shift+B остаётся отдельным
действием и сопровождается коротким лёгким синим оттенком экрана.

Сущность в радиусе 8 клеток на том же Z (включая соседние чанки) вызывает
звуковую тревогу и вопрос о пробуждении. Выбор приостанавливает ходы.
«Продолжить сон» игнорирует уже услышанную сущность до конца этого сна;
она всё ещё может двигаться и атаковать. Esc в вопросе будит игрока.
В определении `game.monsters.MONSTERS` можно указать `sleep_warning` — ключ
локализации текста тревоги. Заготовлены `m.sleep_wake_legs`,
`m.sleep_wake_slap`, `m.sleep_wake_unknown`; новые NPC не добавляются автоматически.

**F2 → Управление**: выберите «Для новых игроков» или «Олдскульный».
В первом наборе: WASD — движение, Shift+движение — бег, E/Enter —
взаимодействие (на лестнице — переход, на предмете — подбор), Tab — меню
действий, I — инвентарь, Space — ожидание, R — отдых, X — смена оружия.
Использование еды, бутылок, документов и артефактов доступно из инвентаря;
остальные действия — через меню. F2 — настройки, / — справка.

Олдскульный набор сохраняет прежние буквенные команды и numpad. Камеры
F5/F6/F7, F11 и мышь работают как раньше. Назначения сохраняются отдельно
для каждого набора. «Сбросить настройки» в списке клавиш сбрасывает только
активный набор. Старые настройки загружаются как олдскульный набор.

Запуск: `python main.py`. Настройки открываются клавишей **F2**.

* **F5** — классическая ASCII-карта.
* **F6** — вид от первого лица: программный raycasting в духе ранних Doom/Wolfenstein.
  WASD — шаги относительно направления взгляда (A/D — вбок), стрелки
  влево/вправо — поворот. Игра остаётся пошаговой.
* **F7** — объёмная карта-доска. Стрелки влево/вправо — вращение,
  **Page Up / Page Down** — наклон от вида снизу до вида строго сверху,
  колесо — масштаб, **Home** — показать всю доску. Удерживайте среднюю
  кнопку мыши и двигайте мышь для вращения и наклона.
* **F11** — полноэкранный/оконный режим.
* **ПКМ** — сведения об объекте; ЛКМ — ход к видимой клетке.
  При прицеливании выберите объект мышью и подтвердите Enter.

В настройках доступны режим **«Авто (по экрану)»** и разрешения **680×240, 800×600,
1024×768, 1280×720, 1366×768, 1600×900, 1920×1080, 2560×1440**. В авторежиме игра
при запуске сама выбирает окно примерно на 85 % экрана, сохраняя пропорции 16:9 и не
превышая 1920×1080, и центрирует его. Окно можно растягивать мышью: канва и интерфейс
подстраиваются на лету, без перезапуска и без пересоздания GL-контекста; после ручного
растягивания режим становится «фиксированным» и размер запоминается.
Изображение сохраняет пропорции; по краям могут появляться поля. На 680×240
текст существенно мельче — для комфортного чтения лучше 1280×720 и выше.

В разделе «Графика»: режим камеры, качество лучей первого лица, освещение,
туман, контуры и отображение всего рельефа доски. Полная карта показывает
геометрию уровня, но предметы и монстры остаются ограничены полем зрения.
Изменения сохраняются в `save/settings.json`.

## Программируемые материалы

`engine/shaders.py` содержит функцию `shade`: Python-шейдер цвета граней,
дистанционного тумана и мерцающего света. Измените её и перезапустите игру,
чтобы настроить палитру или формулу освещения. `engine/views.py` строит грани
через `pygame.draw.polygon` и линии через `pygame.draw.line`; здесь можно
добавлять собственную геометрию. Это CPU-рендеринг, не GLSL/Godot и не
GPU-шейдеры. Новые зависимости не требуются.

Проверка новых режимов без окна: `python tests/graphics_test.py`.

## Tileset-графика и редактор

### Изображение → ASCII-мозаика

Запустите `python tileset_editor.py`, нажмите **«Картинка → ASCII-спрайт…»**.
В отдельном окне откройте PNG/JPG/BMP/WebP, выберите детализацию (4–96
столбцов), набор символов, цветной/белый режим, инверсию и контраст.
Нажмите «Преобразовать / обновить» для сравнения с исходником.

«Назначить символу» создаёт PNG-мозаику в текущем моде и привязывает её к
указанному игровому символу. Затем сохраните набор в основном редакторе и
включите tileset. Существующая atlas-привязка этого символа заменяется.
Отдельно доступны экспорт PNG и UTF-8 текста. Прозрачный фон PNG сохраняется;
Для однотонного фона включите «Удалить фон»: цвет определяется по углам
или выбирается вручную, допуск регулируется ползунком. По умолчанию
удаляется только фон, связанный с краями; отключение «Только от краёв»
убирает выбранный цвет и внутри объекта. Нажмите «Преобразовать / обновить»
после изменения допуска. Прозрачность видна на шахматной подложке.
Кнопка «PNG без фона» экспортирует обработанную картинку до ASCII-конвертации.
Исходник сохраняется в памяти нетронутым: выключите галочку для возврата.
При удалении фона большие изображения уменьшаются до 1024 px по длинной
стороне для быстродействия. Это удаление по цвету, не AI-сегментация:
сложный фотографический фон может потребовать предварительной обработки.

Это много символов внутри одного спрайта, а не увеличение числа клеток мира.
На размерах 16–64 px высокая детализация теряется: для игровых объектов
начните с 4–12 столбцов. Белый вариант подходит для автоперекраски.
Конвертация работает офлайн и не добавляет вычислений в игровой цикл.

Игра сохраняет ASCII в качестве безопасного резервного режима. Для создания
собственного набора запустите из папки проекта:

```powershell
python tileset_editor.py
```

Редактор показывает оригинальный ASCII-символ и его кастомный tileset рядом,
позволяет импортировать PNG для символа, выбирать размер набора 16/24/32/48/64,
включать автоперекраску нейтральных серых/белых спрайтов и активировать мод.
В редакторе есть справочник всех игровых символов:
`█/▓/▒` — стены, `.` — пол, `+` — дверь, `@` — игрок, `>`/`<` — лестницы,
`!` — бутылки с жидкостью, `?` — документы, `/` — артефакты, `)` — оружие.
Символы будущих сущностей берутся из реестра и регистрозависимы.
Для atlas редактор показывает сам spritesheet с клеточной сеткой: клик по
клетке автоматически выставляет X/Y и назначает её текущему символу.
Колесо мыши меняет масштаб просмотра, жёлтая рамка показывает выбранную
клетку, а поля X/Y остаются доступными для точной ручной настройки.
Моды хранятся в `mods/graphics/<имя>/`. Их формат описан в
`mods/graphics/README.md`. В игре это также доступно в **F2 → Graphics**.

Если `manifest.json`, PNG-файл или его формат повреждены, соответствующий
символ автоматически рисуется обычным ASCII. Ошибка одного спрайта не ломает
загрузку игры и не влияет на остальные символы.
