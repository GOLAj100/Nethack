# Graphics mods

Каждая подпапка — отдельный необязательный graphics mod.

Минимальный формат:

```json
{
  "tile_size": 32,
  "tiles": {
    "@": "player.png",
    "#": "wall.png",
    ".": "floor.png"
  }
}
```

Вместо отдельных файлов можно использовать один atlas/spritesheet. При
`tile_size: 32` координаты `[column, row]` считаются клетками по 32 пикселя:

```json
{
  "tile_size": 32,
  "sheet": "sheet.png",
  "atlas": {
    "@": [0, 0],
    "#": [1, 0],
    "k": [2, 0]
  }
}
```

Также поддерживается прямоугольник в пикселях: `"@": [64, 32, 32, 32]`.
Для atlas есть кнопки «Импорт atlas» и «Назначить atlas-клетку» в редакторе.

Размер клетки: 16, 24, 32, 48 или 64 пикселя. PNG-файлы могут быть цветными
или нейтральными (серые/белые). При включённой автоперекраске нейтральный
спрайт тонируется цветом объекта. Отсутствующие и повреждённые файлы всегда
заменяются ASCII-символом.
