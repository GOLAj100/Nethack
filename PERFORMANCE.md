# Монитор производительности

Нажмите **F12** в игре. В левом верхнем углу появится лёгкая панель:

* средний FPS и время кадра;
* p99 и максимальный кадр — полезно ловить редкие лаги у мебели/чанка;
* отдельное время Update, Draw и Present;
* CPU процесса и общая CPU-загрузка;
* RAM процесса (RSS) и общая RAM;
* текущий backend, GPU, количество кэшированных чанков;
* график последних 150 кадров с линией бюджета 16.67 мс.

В меню **F2 → Отладка** добавлены включение монитора и сброс замеров. F12 можно
нажать повторно, чтобы скрыть панель. `psutil` добавляет CPU/RAM ОС:

```powershell
python -m pip install -r requirements-monitor.txt
```

Без psutil игра всё равно показывает FPS, frame time, Update/Draw/Present и
backend; системные CPU/RAM будут обозначены как unavailable.

Монитор не измеряет загрузку GPU/VRAM: надёжное чтение этих величин зависит от
драйвера (NVIDIA NVML, Windows Performance Counters и т.д.). Рендер-метрики
в игре точнее для поиска проблем: если Draw высокий — дорогая отрисовка;
если Update высокий — AI, свет, чанки или логика; если Present высокий —
масштабирование/вывод окна.
