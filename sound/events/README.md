# Effects per event

Place a WAV/OGG/MP3 named after an event here to override its neutral synthesized
cue: `step.wav`, `door.wav`, `door_bump.wav`, `pickup.wav`, `hit.wav`, `miss.wav`,
`player_hurt.wav`, `sleep_alarm.wav`, `eat.wav`, `drink.wav`, `read.wav`,
`menu.wav`, `select.wav`, `death.wav`. Restart the game after adding files.

One event always uses the same effect. The older drum/sample folders are kept
but are no longer randomly used for gameplay effects.
