# B-Level profiles

Файлы здесь описывают правила генерации B-Level, а не отдельные сохранённые
карты. Доступны профили `0.json`–`20.json`; детали —
[`../docs/MAIN_NINE.md`](../docs/MAIN_NINE.md).

`World Z` — координата вертикального слоя мира. `z_min` и `z_max` профиля
ограничивают существующие слои только для конкретного B-Level; они не являются
ограничением движка. 3D-карта показывает максимум пять слоёв вокруг фокуса,
если такие слои существуют.

Level 0 сохраняет вертикальный тест на Z=−1..1. Level 6 имеет поверхность
Z=0 и подземные коридоры Z=−1; уровни 1–5 и 7–20 имеют только Z=0.
Уровень 7 добавляет холодную воду, а уровни 10, 13 и 16 — проходимые
водоёмы/затопленные секции. Тайлы воды проходимы только при `swimming`,
движение по ним расходует выносливость; холод и урон настраиваются профилем.
Выходы между B-Level хранятся в `Level.exits`, отдельно от вертикальных лестниц.
Переходы между чанками Level 0 бесконечны в пределах координат мира: новый
чанк 80×50 создаётся детерминированно из seed и координат.
