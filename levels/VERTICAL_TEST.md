# Вертикальная тестовая сцена Level 0

Начните **новую игру**: старые сохранения сохраняют свой профиль мира и чанки.
В `0.json` включён `vertical_test`, этажи Z=-1,0,1.

В каждом новом чанке (координаты локальные, 80×50):

* x=10..29, y=10..29 — высокий зал. Пол на Z=0, открытый объём на Z=1.
* x=40..59, y=10..29 — зал с ямой. Нижний пол на Z=-1.
* x=42..57, y=20..21 — мост на Z=0.
* (41,20) — лестница Z=0 → -1 и обратная лестница Z=-1 → 0.
* (30,20) — лестница Z=0 → 1 и обратная лестница Z=1 → 0.
* В боковых стенах залов на y=20..21 есть проёмы в коридоры.

На лестнице используйте существующие действия `<` / `>` (подъём / спуск).
Выход на клетку без пола переносит на нижний опорный этаж: один этаж даёт
50% шанс без урона, иначе 1d6; выше — Nd6. Падение пока без анимации.

## Камера

F6 — настоящее объёмное программное трассирование. PageUp/PageDown меняют
вертикальный угол; средняя кнопка мыши или Alt + движение мыши — осмотр.
Home сбрасывает наклон. Если включён debug fly, PageUp/PageDown перемещают
самого игрока по Z, поэтому для проверки наклона отключите полёт.

Рендер использует внутреннюю сетку лучей 64/96/128 пикселей по ширине для
низкого/среднего/высокого качества, масштабируя результат до размера окна.
Это компромисс качества и CPU-нагрузки, а не аппаратное ускорение.

## Карта

F7 — осмотр без ходьбы игрока. `,`/`.` выбирают Z, F8 переключает отдельный
слой и объём до пяти слоёв. Стрелки влево/вправо вращают карту,
PageUp/PageDown наклоняют; средняя кнопка/Alt — вращение мышью, колесо — зум.
Карта ограничена текущей областью 80×50, а не всем бесконечным миром.
«Весь рельеф» показывает неисследованную геометрию; при выключении видны
исследованные клетки. F5/F6 возвращают игровые режимы.

### Настройки и производительность

По умолчанию карта показывает только исследованную часть выбранного Z;
контуры отключены. «Карта: раскрыть неисследованное» — отдельная опция
просмотра всей геометрии, а не дистанционный туман первого лица.
«Карта: только выбранный Z» сохраняется между запусками; F8 меняет эту же
настройку. Качество лучей относится только к первому лицу.

Без контуров полные карты объединяют соседние плоские участки в полосы,
уменьшая число полигонов. Контуры требуют отдельных клеток и потому дороже.
Включение объёма умножает объём геометрии на число этажей. Неисследованные
клетки скрыты на каждом этаже независимо; уже исследованные области старого
сохранения не стираются при изменении настроек.

Замер поворотов камеры: `python tests/render_options_test.py`.
